# File Upload Interview Notes

## What Is A File Upload Vulnerability?

Improper validation of uploaded files.

---

## Worst Impact?

```text
Remote Code Execution
```

---

## Why Are Blacklists Weak?

Attackers can use:

```text
Alternative Extensions
```

---

## What Is A Polyglot File?

```text
One File
Two Formats
```

---

## What Is A Race Condition?

Timing issue between:

```text
Upload
Scan
Deletion
```

---

## Best Defense?

```text
Whitelist
+
Safe Storage
+
Execution Disabled
```
