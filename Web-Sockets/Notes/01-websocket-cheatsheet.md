# WebSocket Cheatsheet

- Full-duplex, bi-directional.
- Initiated over HTTP.
- Long-lived.
- `wss://` = TLS.
- `ws://` = unencrypted.
- Burp Proxy = interception.
- Burp Repeater = replay/modification/generation.

Main areas:
1. Message manipulation.
2. Input-based vulnerabilities.
3. Handshake flaws.
4. CSWSH.
5. Blind vulnerabilities/OAST.
