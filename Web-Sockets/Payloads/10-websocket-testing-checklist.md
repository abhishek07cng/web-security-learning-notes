# WebSocket Testing Checklist

- [ ] Identify WebSocket functionality.
- [ ] Review WebSocket history.
- [ ] Capture both message directions.
- [ ] Modify messages.
- [ ] Replay messages.
- [ ] Generate messages.
- [ ] Test input-based vulnerabilities.
- [ ] Inspect the handshake.
- [ ] Test header/session design flaws.
- [ ] Check CSRF protection.
- [ ] Consider OAST for blind issues.
- [ ] Verify safe server/client handling.
