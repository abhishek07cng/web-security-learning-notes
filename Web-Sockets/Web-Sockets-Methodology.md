# WebSockets Methodology

1. **Discover** — find WebSocket functionality.
2. **Capture** — inspect the handshake and messages.
3. **Understand** — identify message structure and session context.
4. **Tamper** — modify and replay messages.
5. **Test handshake** — inspect cookies, headers, session handling, and CSRF protection.
6. **Assess impact** — verify server/client behavior.
7. **Document** — record request, modification, behavior, and impact.
