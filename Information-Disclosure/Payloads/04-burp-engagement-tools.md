# Burp Engagement Tools Cheat Sheet

## Search

Purpose:

Locate keywords within responses.

Useful keywords:

```
error

password

admin

SQL

Exception
```

---

## Find Comments

Purpose:

Locate HTML comments.

Useful for finding:

- TODO items
- Hidden endpoints
- Debug notes

---

## Discover Content

Purpose:

Locate hidden files and directories.

Examples:

- Backup files
- Admin pages
- Debug resources

---

## Logger++

Purpose:

Log requests and responses.

Useful for:

- Reviewing traffic
- Filtering responses
- Identifying anomalies

---

## Repeater

Purpose:

Modify requests manually.

Useful for:

- Triggering errors
- Testing hidden functionality
- Verifying findings

---

## Intruder

Purpose:

Automated fuzzing.

Useful for:

- Parameter testing
- Response comparison
- Error generation
