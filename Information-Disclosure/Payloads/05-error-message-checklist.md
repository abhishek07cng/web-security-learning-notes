# Error Message Checklist

When an error occurs, inspect the response for:

☐ Framework name

☐ Framework version

☐ File path

☐ Database information

☐ Stack trace

☐ Server software

☐ Programming language

☐ Template engine

☐ Internal implementation details

---

## Compare

- Status Code
- Response Length
- Error Type
- Processing Time

---

## Ask Yourself

Does this reveal:

- Sensitive technical information?

- Existing resources?

- Internal application logic?

- Software versions?

If yes, document the finding and assess its security impact.
