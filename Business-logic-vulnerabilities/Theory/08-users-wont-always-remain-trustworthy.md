# Users Won't Always Remain Trustworthy

## Overview

Applications often trust authenticated users too much.

However:

```text
Authenticated User
≠
Trusted User
```

---

# Examples

Users may:

```text
Abuse Coupons
Manipulate Prices
Replay Requests
Automate Actions
```

---

# Common Mistake

Developer assumption:

```text
Logged In User
        ↓
Behaves Correctly
```

---

# Reality

Attackers abuse functionality.
