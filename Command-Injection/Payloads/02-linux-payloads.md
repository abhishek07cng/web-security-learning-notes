# Useful Linux Commands

## Current User

```bash
whoami
```

---

## Operating System

```bash
uname -a
```

---

## Network Configuration

```bash
ifconfig
```

---

## Active Connections

```bash
netstat -an
```

---

## Running Processes

```bash
ps -ef
```

---

# Purpose

These commands help identify:

- Current user
- Operating system
- Network configuration
- Active network connections
- Running processes

---

# Key Takeaways

These reconnaissance commands are useful after confirming Command Injection.
