# Useful Windows Commands

## Current User

```cmd
whoami
```

---

## Operating System

```cmd
ver
```

---

## Network Configuration

```cmd
ipconfig /all
```

---

## Active Connections

```cmd
netstat -an
```

---

## Running Processes

```cmd
tasklist
```

---

# Purpose

These commands provide basic reconnaissance on Windows systems after confirming command execution.

---

# Key Takeaways

Windows requires different commands than Unix-based systems for gathering system information.
