# Reconnaissance Commands

## Linux

```bash
whoami
uname -a
ifconfig
netstat -an
ps -ef
```

---

## Windows

```cmd
whoami
ver
ipconfig /all
netstat -an
tasklist
```

---

# Purpose

Gather basic information about:

- User account
- Operating system
- Network configuration
- Active connections
- Running processes

---

# Key Takeaways

Reconnaissance helps understand the environment after confirming OS Command Injection.
