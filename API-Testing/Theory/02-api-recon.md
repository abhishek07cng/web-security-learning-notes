# API Recon

## Overview

Recon is the most important stage of API testing.

Goal:

```text
Map The Attack Surface
```

---

# Find

```text
Endpoints
Parameters
Methods
Authentication
Rate Limits
```

---

# Sources

```text
JavaScript Files
Proxy History

Error Messages
```

# Typical Flow

```text
Discover Endpoint
        ↓
Understand Requests
        ↓
Identify Parameters
        ↓
Explore Methods
```

# Questions
