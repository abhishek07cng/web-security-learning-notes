# What Is API Testing?

## Overview

APIs (Application Programming Interfaces) enable applications and systems to communicate and exchange data.

Since modern web applications rely heavily on APIs, vulnerabilities in APIs can impact:

```text
Confidentiality
Integrity
Availability
```

---

# API Testing

API testing focuses on:

```text
Endpoints
Methods
Parameters
Authentication
Data Formats
Hidden Functionality
```

---

# Examples

```text
REST APIs
JSON APIs
GraphQL APIs
Internal APIs
```

---

# Common Vulnerabilities

```text
Mass Assignment
Broken Authentication
Broken Access Control
SSPP
Hidden Endpoints
```

---

# Why API Testing Matters

Modern websites are largely APIs.

Many classic vulnerabilities exist inside APIs.

---

# Key Takeaways

- APIs increase attack surface.
- Hidden functionality often exists.
- API vulnerabilities can impact entire applications.
